webRAW-Serial - isolated transport prototype

Standalone test page for the Web Serial transport experiment - see webRAW-Serial.cpp's file header for the full reasoning. Not part of the shared stream.html. Writes [4-byte sync marker][4-byte LE compressed length][raw deflate bytes] per frame directly over USB Serial and waits for a single ack byte back before sending the next - no WiFi, no AsyncTCP, board must stay plugged into this computer for the whole session. The sync marker lets the device recover deterministically if byte-stream alignment is ever lost (e.g. a previous session ending mid-frame) instead of guessing.

This prototype has no WiFi, so there's no /boardinfo endpoint for this page to read the panel's real size from the way stream.html does - these two fields must be set by hand and exactly match the device's actual WIDTH/HEIGHT. Getting the total pixel count right but the width/height swapped (e.g. 600x450 instead of 450x600) won't error out - decompression will still produce the right number of bytes - but every row gets sliced at the wrong offset, scrambling the image instead of failing cleanly. On the 2.41" T4-S3 specifically, the device runs in portrait (450x600), not its native landscape (600x450) - see webRAW-Serial.cpp's setRotation(1) comment for why (a display-tearing fix, unrelated to this page). The 1.47"/1.91" boards don't have that rotation applied and use their native landscape dimensions.

Idle. Click "Connect device" first - this is the same one-time port-selection prompt this project's own browser flasher uses.
